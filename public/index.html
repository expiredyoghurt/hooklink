🪝 Hook & Link

Cheat card

Flashback story: 1. the present story, 2. a hook, 3. the flashback (the memory), 4. a link back that shows how the memory changed the character.

Hook (trigger): what pulls a character from now into a memory. A smell, sound, taste, touch, or a personal object is a strong hook. Example: the smell of roasted chestnuts pulls Mei back to rainy days with Grandpa. In Spot the Hook, read the memories and pick the ONE hook that opens the best memory for the problem in the story.

Link: a part of the story that ties the memory back. To name it, ask: what is the same in the memory and in this part of the story?

  • Same object: the torn bag in both scenes.
  • Same action: hiding a mistake, then hiding it again.
  • Same feeling: scared then, scared now.
  • Same words: a line from the memory that the character says later.

Rankings: 🌟 Ideal = a personal object or sense, noticed just when the character must choose, with a link that carries the lesson. 👍 Good = a real hook, but weaker timing or a less central memory. 🙂 Workable = it can work, but the hook is broad (a place) or the link is only a feeling.
